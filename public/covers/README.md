# Game Covers

Place your game cover images here.

## Requirements

- **Aspect Ratio**: 2:3 (portrait, Steam-style)
- **Recommended Size**: 400x600px or 600x900px
- **Format**: JPG or PNG
- **Naming**: Must match the game `id` from the database

## Example Filenames

- `darktide.jpg`
- `helldivers2.jpg`
- `sonsforest.jpg`
- `deeprock.jpg`
- etc.

## Where to Get Covers

1. **SteamGridDB**: https://www.steamgriddb.com/ (recommended)
2. **Steam Store**: Right-click game images and save
3. **IGDB**: https://www.igdb.com/

## Quick Tip

If you don't have all covers yet, you can use placeholder images or solid colors temporarily. The app will still function.
